# Issue tracker

This repo tracks work in GitHub Issues.

## Workflow

- Use the GitHub CLI (`gh`) for issue creation and lookup.
- Keep issue titles concise and implementation-focused.
- Prefer linking issues from pull requests and repo notes when closing work.

## Configuration

- Provider: GitHub
- Repository: `michaelaird/weekly-summary`
- PRs as a request surface: off

## Notes

This setup is the default for the engineering skills and can be edited later if the repo moves to a different tracking system.
